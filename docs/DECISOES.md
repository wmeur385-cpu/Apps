# Decisões

- 02/10: mais recente vence entre declarações de endereço; cópia CRM→ERP não conta como voto independente. Alternativa descartada: maioria simples (erraria em ~50 clientes).
- 02/10: pergunta com nome que serve para vários clientes → avisar, não chutar. Alternativa descartada: escolher o mais parecido.
- 02/10: calibração com critérios pré-registrados; a configuração nova NÃO virou padrão por furar o teto de pendências em 0,4 ponto. Alternativa descartada: afrouxar o teto depois de ver o número.
- 02/10: permissão por fonte, identidade recalculada só com o que o perfil vê; contagem de ocultos é dita, conteúdo não.
- 02/10: laudo tipa colunas pelo conteúdo, nunca pelo nome; o nome só entra como pista para marca de importação. Alternativa descartada: mapa de nomes de coluna por sistema (quebra no primeiro cliente com nomes diferentes).
- 02/10: bancada mede a resposta, não a entidade (um sistema externo não expõe entidade); a diferença para o benchmark interno é declarada e testada (≤ 1 ponto). Alternativa descartada: exigir que todo adaptador devolva a entidade.
- 02/10: perfilar.js (laudo preso ao esquema desta base) fica como referência; laudo.js é o produto.
